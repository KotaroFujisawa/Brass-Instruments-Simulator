# C管セルパンの物理モデルと音程

6つの指穴を持つキーなしのC管セルパンを対象とします。運指表に従って実音C2〜C4を鳴らし、管長や唇を音ごとに調律する前の音程を調べます。比較にはA4 = 440 Hzの12平均律を使います。

## 管体と指穴

管体は *The Science of Brass Instruments* 図4.56に示される三つの円すい台です。管体入口から中心線に沿った位置0、1.00、1.62、2.20 mの管半径を、それぞれ6、20、32、52 mmとしました。図7.55(a)の外側にふくらむカップの計測曲線を読み取り、スロートの短い一定径区間と接続部を補いました。マウスピース長は43.8 mm、管体との接続部は3 mmです。S字の中心線を展開し、同じ断面積を持つ軸対称格子で計算します。[教科書](https://doi.org/10.1007/978-3-030-55686-0) · [管体](../../data/serpent_bore_fig456.csv) · [マウスピース](../../data/serpent_mouthpiece_fig755a.csv)

指穴は唇側から1〜6番と呼び、3孔ずつ二組に分かれます。第1孔を図4.56の位置に置き、第2〜6孔にはNational Music Museum所蔵のBaudouin製セルパン（NMM 07123）の孔間隔を使いました。孔径は同館の記録範囲14.3〜15.1 mmの中間値14.7 mmで統一し、孔のチムニー高は7 mmと仮定しました。異なる資料の寸法を組み合わせた形状なので、各ピークの周波数や音程差の数値はこの再構成形状に対応します。[NMM 07123の収蔵記録](https://emuseum.nmmusd.org/objects/9121/serpent-c-or-lowpitch-d) · [指穴のデータ](../../data/serpent_toneholes_reconstructed.csv)

指穴を開くと、チムニーの慣性と放射の周波数依存性を含む境界を管に接続します。波は開孔から放射されるほか、孔より下流の管を通ってベルにも到達します。閉孔は剛体壁として扱います。軸対称化では孔の周方向位置、曲がりによる音場の変化、放射された音による孔どうしの外部連成を省略します。[側孔とベルの境界モデル](EUPHONIUM_OPHICLEIDE_MODEL.md#管内の連成と放射)

## 運指と音階

Christopher Monk Instrumentsの6孔C管運指表から実音C2〜C4の25音を読み取りました。たとえばD2は6番、E2とE3は5・6番を開き、G2は3〜6番を開きます。B2とC3、B3とC4はそれぞれ同じ全閉運指です。これらの隣接音を吹き分けるには、同じ管の共鳴に対して唇を調整する必要があります。A3、B♭2、B♭3には表に記載された別運指があります。C♯2とC♯3は6番の半開孔を使うため、全開・全閉の孔を比較する今回の計算から除きました。音声はCメジャーの15音です。[製作者の運指表](https://www.jeremywest.co.uk/uploads/1/4/6/0/14606206/fingering_chart_serpent_in_c.pdf) · [運指データ](../../data/serpent_fingerings.json)

## 共鳴と発音の比較

線形解析では、管体を短い区間に分けて伝達行列でつなぎ、開孔を途中の分岐として加えます。唇の面で見た入力インピーダンスのピークを求め、A4 = 440 Hzの各実音と比較します。さらに全閉の最低ピークをC2に対応させ、各音に共通する基準音のずれを差し引いた値も示します。ここでは基準を換算するだけで、形状は同じです。目標に最も近いピークの周波数は、発音しやすい候補を比較するための指標です。実際にどの振動が持続するかは、唇と管の時間発展で判定します。

教科書の図4.57は、全閉時にほぼ整数比で並ぶ共鳴が、第1孔を開くと低周波で不均等に動くことを示しています。図7.62・7.63のBaudouin製D管（EU 3606）の実測でも、ベル側の二孔を開いたときの共鳴移動は低次の二つでおよそ+400セント、上位ではより小さい値です。管の太さに対して孔が小さいため、高い周波数ほど開孔の影響を受けにくくなります。この周波数ごとの違いと、指が届くように孔を二組にまとめた配置により、各運指で音程が均等に動くかを調べる必要があります。[教科書の図4.57、7.62、7.63](https://doi.org/10.1007/978-3-030-55686-0)

E3の運指であるベル側の2孔開放では、図4.96と同じく候補基音 $f$ の第1〜4倍音における入力インピーダンス実部の加重和を求めます。重みは弱奏相当が `(1, 0.5, 0.2, 0.1)`、強奏相当が `(1, 1, 0.7, 0.4)` です。同図では強奏側で、目標約165 Hzより約15 Hz低い候補が目立ちます。加重和は管体の共鳴を比較する指標です。実際に吹奏圧で発音が変わるかは、以下の時間領域の比較で調べます。[教科書の図4.96](https://doi.org/10.1007/978-3-030-55686-0)

時間領域では、Adachi–Satoの2自由度唇モデルと軸対称の圧縮性Eulerソルバーを双方向に連成します。唇の固有振動数は全音で目標の1.12倍、吹奏圧は2.85 kPaに固定します。E3は同じ運指と唇設定のまま1.45、2.15、2.85 kPaを比べます。放射音から持続周波数と周期性を測定し、周期的な振動が得られなかった試算も記録します。[Adachi–Satoの唇モデル](https://doi.org/10.1121/1.414601) · [軸対称ソルバー](AXISYMMETRIC_MODEL.md)

## 計算結果

第1孔を開くと、第1共鳴は71.58 Hzから109.90 Hz、第2共鳴は134.52 Hzから139.58 Hzへ動きました。教科書の図4.57では、図からの概読で第1共鳴が約71 Hzから105 Hzへ動き、第2共鳴の移動は数Hzです。第3共鳴の変化も、計算の201.60 Hzから230.20 Hzに対し、図では約207 Hzから230 Hzです。線形計算の軸方向区間長を半分にしたとき、全開・全閉で表せる23音の比較用ピーク周波数は最大0.67セント変化しました。[教科書の図4.57](https://doi.org/10.1007/978-3-030-55686-0_4)

同じ全閉運指のB2とC3は、時間領域の計算で132.84 Hzと133.79 Hzになりました。間隔は約12セントで、12平均律の半音は100セントです。15音中13音で持続音が得られ、A3とC4はこの唇設定で持続発音が成立しませんでした。音階のWAVには各試算の放射音を共通のゲインで収録しています。

E3の線形加重和では、弱奏重みで172.53 Hzが最も大きく、138.21 Hzの低い候補はその0.59倍の高さでした。強奏重みでは138.23 Hzの候補が172.55 Hzの山の1.17倍になりました。図4.96では低い候補が約152 Hzに現れ、強奏でも主ピークより低い山です。低い候補が強まる傾向は共通し、周波数と山の順位は再構成した形状に依存します。[教科書の図4.96](https://doi.org/10.1007/978-3-030-55686-0_4)

同じ運指を使った時間領域の圧力比較では、1.45 kPaはほぼ無音で、2.15 kPaでは185.20 Hz、2.85 kPaでは191.03 Hzで安定しました。二つの持続音の差は約54セントの上昇です。唇の固有振動数を165.0 Hzに固定した別の試算でも、2.85 kPaの168.04 Hzから3.50 kPaの175.64 Hzへの上昇でした。加重和で強くなる低い候補と、設定した唇が実際に選んだ発音周波数を区別して評価します。

## 唇と吹奏圧の調整

管体とマウスピースの寸法を固定し、各音の唇の固有振動数、静止時の開き、減衰、吹奏圧を調整しました。A3には運指表の替え指を使いました。D3では、開孔の別の組み合わせや、標準運指で開く第6孔を部分的に開ける条件も試しました。部分開孔は、指が覆っていない面積と同じ円形開口で近似します。

音程の目標はA4 = 440 Hzの12平均律です。比較用の許容差を15セントとし、口元の条件で生じた放射音の基本周期を測りました。各音を静止状態から0.65秒間計算し、90 msの間隔でつなぎます。使用した設定は[調整後の演奏プリセット](../../data/performance_serpent_tuned.json)に記録しました。

出力WAVの持続部を目標音高に依存しない自己相関法で再測定したところ、15音すべてで周期的な発音が得られ、14音が±15セント以内に入りました。全閉を共用するB2とC3の間隔は約12セントから95.5セントに広がりました。D3は第6孔を面積比42%にして発音が安定しましたが、持続部は約143.13 Hzで、目標の146.83 Hzより44セント低い結果です。

実演でも、同じ全閉運指を使うBとCは唇の調整で吹き分けます。Campbellによる歴史的セルパンの測定では、全閉の音はよくまとまり、開孔した音では唇による音程の可変幅が大きいと報告されています。[Iowa State Universityの演奏資料](https://antiqua.music.iastate.edu/instrument/serpent) · [Campbellの入力インピーダンス測定](https://www.ioa.org.uk/system/files/publications/DM%20CAMPBELL%20INPUT%20IMPEDANCE%20MEASUREMENTS%20ON%20HISTORIC%20BRASS%20INSTRUMENTS.pdf)

## 再計算

リポジトリのルートから実行します。音声計算にはNVIDIA GPUとNVRTCが必要です。[実行環境の準備](../../README.md#インストール)

```sh
python src/analyze_serpent.py
python src/render_serpent.py
python src/render_serpent.py --preset data/performance_serpent_tuned.json
```

出力先は `output/serpent_axisymmetric/` です。線形解析は `serpent_impedance.json` と `serpent_intonation.png`、時間領域の計算は `serpent_playing.json` と、音階・E3の圧力比較のWAVを生成します。E3の比較では1.45、2.15、2.85 kPaの順に再生されます。二つのWAVに同じ出力ゲインを適用します。

演奏プリセットを指定すると `serpent_C2_C4_tuned.wav` と `serpent_tuned_playing.json` が生成されます。
